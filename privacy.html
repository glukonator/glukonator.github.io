mail_client privacy policy

Last updated: 2026-10-31.

mail_client is a personal tool used only by its owner with the owner's own Google account.

Data accessed

With the owner's consent, the app uses the Gmail API scope gmail.modify to read messages, change labels and create drafts. It does not send email and does not delete messages.

Storage

OAuth tokens, a journal of label changes and any files the owner exports are stored on the owner's computer. The app has no server of its own and keeps no Google user data anywhere else.

Use and sharing

Google user data is used only to show mail to the owner and to carry out the owner's requests. Message content the owner works with is passed to the AI assistant the owner runs, which processes it under that assistant provider's terms. The data is not sold, is not used for advertising and is not shared with anyone else.

Removing access

Access can be revoked at any time on the Google Account permissions page.
